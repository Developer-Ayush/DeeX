# DeeX Testing Framework

This directory contains test methodologies, record procedures, and verification frameworks for DeeX.

## Required Test Record Fields

Per Section 15.8 of the DeeX Master Development Plan v1.0, every executed test must record exactly these fields:

1. **Procedure**: Step-by-step instructions executed during the test.
2. **Expected Result**: Precise baseline or required output behavior.
3. **Actual Result**: Observed outcome during test execution.
4. **Reproducible Evidence**: Log snippets, test output files, command traces, or image hashes verifying the result.

Blank test execution records must be created using `docs/testing/test-record-template.md`.
