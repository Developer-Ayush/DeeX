## 1. Warnings

1.1. **Data Wipe Warning**: Unlocking the bootloader or executing `fastboot flashall -w` / `fastboot -w` strictly forces a complete wipe of all user data, encryption keys, and internal storage on the target device.
[Primary Source: Google Android Source — Running Android Devices — Unlocking the Bootloader, `https://source.android.com/docs/setup/build/running#unlocking-the-bootloader`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

1.2. **Dedicated Development Device Requirement**: This procedure MUST be performed ONLY on a dedicated hardware development device. Do not use a personal phone or a device containing unbacked-up personal data.
[Primary Source: DeeX Master Development Plan v1.0, Section 5.1 / 17.7, Access Date: 2025-05-16, Confidence: `VERIFIED`]

1.3. **Warranty & Feature State Warning**: Unlocking the bootloader on Google Pixel devices alters the device security posture. Certain security-sensitive features (such as SafetyNet / Play Integrity hardware attestation for third-party banking applications) will report an unlocked bootloader state.
[Primary Source: Google Android Source — Verified Boot, `https://source.android.com/docs/security/features/verifiedboot`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

1.4. **Recovery Path**: In the event of an unbootable state or bootloop, the target device can be restored to full working factory condition using Google's official Pixel factory images or the web-based Android Flash Tool.
[Primary Source: Google Developers — Factory Images for Nexus and Pixel Devices, `https://developers.google.com/android/images`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

## 2. Preconditions

2.1. **Battery Level**: Verify that the Google Pixel 8 battery charge level is at least **50%** before initiating any bootloader unlocking or flashing operations to prevent power loss mid-flash.
[Primary Source: Google Android Flash Tool Help — Requirements, `https://flash.android.com/about`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

2.2. **Host Cable & Port Guidance**: Connect the device directly to a native USB host port using a known-good USB-C to USB-C 3.1/3.2 data cable. Avoid USB hubs or front-panel extenders during fastboot operations.
[Primary Source: Google Android Flash Tool Help — Troubleshooting, `https://flash.android.com/about`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

2.3. **Host Tool Requirements**: Ensure the host environment has official Android SDK Platform-Tools installed (specifically `adb` and `fastboot`).
- Command version check: `adb version` and `fastboot --version`.
- Platform-specific notes:
  - **Linux**: Configure udev rules for Google vendor ID (`18d1`). If udev rules are not configured, `fastboot` commands will fail due to permission errors.
  - **macOS**: Native USB support via Android SDK Platform-Tools for macOS; no external drivers required.
  - **Windows**: Google USB Driver for Windows must be installed for ADB/Fastboot interface recognition in Device Manager.
[Primary Source: Google Android Developers — SDK Platform-Tools Release Notes, `https://developer.android.com/tools/releases/platform-tools`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

2.4. **Build Artifacts Readiness**: Verify that the baseline build artifacts (`boot.img`, `init_boot.img`, `vendor_boot.img`, `pvmfw.img`, `vbmeta.img`, `super.img`, `system.img`, `vendor.img`, `product.img`, `system_ext.img`) exist in `$ANDROID_PRODUCT_OUT` or the local build output directory, and that their SHA-256 checksums match the recorded values in the build record generated by `tools/make-build-record.sh`.
[Primary Source: Google Android Source — Building Android — Flashing a Device, `https://source.android.com/docs/setup/build/running#flashing-a-device`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

## 3. Preparing the Device

3.1. **Enable Developer Options**:
- On the Pixel 8 device, navigate to **Settings > About phone**.
- Scroll to the bottom and tap **Build number** seven (7) times until the toast message "You are now a developer!" appears.
[Primary Source: Google Android Source — Running Android Devices — Enabling Developer Options, `https://source.android.com/docs/setup/build/running#enabling-developer-options`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

3.2. **Enable OEM Unlocking and USB Debugging**:
- Navigate to **Settings > System > Developer options**.
- Toggle **OEM unlocking** to ON. Enter device passcode if prompted.
- Toggle **USB debugging** to ON. Accept the ADB authorization prompt when host is connected.
[Primary Source: Google Android Source — Running Android Devices — Unlocking the Bootloader, `https://source.android.com/docs/setup/build/running#unlocking-the-bootloader`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

3.3. **Reboot to Fastboot / Bootloader Mode**:
- From the host terminal, run:
  ```bash
  adb reboot bootloader
  ```
- Alternatively, power off the phone, then press and hold **Volume Down + Power** simultaneously until the Fastboot Mode screen appears.
[Primary Source: Google Android Source — Running Android Devices — Fastboot Mode, `https://source.android.com/docs/setup/build/running#obtaining-fastboot-mode`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

## 4. Unlocking the Bootloader

4.1. **Verify Fastboot Connectivity**:
- Execute on host:
  ```bash
  fastboot devices
  ```
- Confirm that the Pixel 8 serial number is displayed alongside `fastboot`.
[Primary Source: Google Android Source — Running Android Devices — Flashing a Device, `https://source.android.com/docs/setup/build/running#flashing-a-device`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

4.2. **Execute Unlock Command**:
- Execute on host:
  ```bash
  fastboot flashing unlock
  ```
- *Data Wipe Warning*: The device screen will display an unlock confirmation prompt warning that unlocking will wipe all user data.
- Use the Volume keys on the phone to highlight **"Unlock the bootloader"** and press the **Power key** to select.
- The bootloader will wipe storage and return to the Fastboot Mode screen showing status `unlocked`.
[Primary Source: Google Android Source — Running Android Devices — Unlocking the Bootloader, `https://source.android.com/docs/setup/build/running#unlocking-the-bootloader`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

## 5. Flashing the Baseline Image

5.1. **Environment Setup on Host**:
- Ensure environment variables point to the compiled AOSP product output:
  ```bash
  export ANDROID_PRODUCT_OUT=/path/to/aosp/out/target/product/shiba
  export PATH=$PATH:/path/to/aosp/out/host/linux-x86/bin
  ```
[Primary Source: Google Android Source — Building Android — Flashing a Device, `https://source.android.com/docs/setup/build/running#flashing-a-device`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

5.2. **Verify Image Checksums Prior to Flashing**:
- Verify SHA-256 checksums of all target images against the generated build record:
  ```bash
  sha256sum $ANDROID_PRODUCT_OUT/*.img
  ```
[Primary Source: DeeX Reproducibility Policy, `docs/specifications/reproducibility-policy.md`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

5.3. **Flash Images via Fastboot**:
- With the device in Fastboot mode (`fastboot devices`), flash all built partitions:
  ```bash
  fastboot flashall -w
  ```
- *Note on `flashall`*: `fastboot flashall -w` automatically flashes `boot.img`, `init_boot.img`, `vendor_boot.img`, `pvmfw.img`, `vbmeta.img`, `dtbo.img`, and dynamic dynamic logical partitions contained in `super.img` (`system`, `vendor`, `product`, `system_ext`) to the active A/B slot, and wipes user data (`-w`).
[Primary Source: Google Android Source — Building Android — Flashing a Device, `https://source.android.com/docs/setup/build/running#flashing-a-device`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

5.4. **A/B Slot Behavior & Handling**:
- Pixel 8 uses Seamless Updates (A/B partitioning). `fastboot flashall` targets the currently active bootloader slot (Slot A or Slot B).
- If manual slot query or switching is required:
  - Query current slot: `fastboot getvar current-slot`
  - Switch active slot if needed: `fastboot set_active a` (or `b`).
[Primary Source: Google Android Source — A/B (Seamless) System Updates, `https://source.android.com/docs/core/ota/ab`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

## 6. First Boot

6.1. **Initiate First Boot**:
- After flashing finishes, reboot the device from fastboot:
  ```bash
  fastboot reboot
  ```
[Primary Source: Google Android Source — Building Android — Flashing a Device, `https://source.android.com/docs/setup/build/running#flashing-a-device`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

6.2. **Expected Behavior**:
- **Warning Screen**: Because the bootloader is unlocked, the device displays the standard Android Bootloader warning screen ("The bootloader is unlocked and software integrity cannot be guaranteed"). Press power or wait 5 seconds to continue boot.
- **Boot Duration**: First boot compiles runtime artifacts and initializes data partitions. Expect first boot to take between **60 to 180 seconds**.
- **Target Result**: Successful boot completes to the default AOSP launcher screen (AOSP Home screen).
[Primary Source: Google Android Source — Verified Boot Boot Flow, `https://source.android.com/docs/security/features/verifiedboot/boot-flow`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

6.3. **Boot Loop / Failure Recovery**:
- If the device fails to boot within 5 minutes or enters a persistent boot loop:
  1. Hold **Volume Down + Power** to force reboot back into Fastboot Mode.
  2. Record the bootloader screen text and any fastboot error messages.
  3. Perform a factory recovery using Google's official Pixel factory restore procedure:
     - Visit `https://developers.google.com/android/images`
     - Download official Pixel 8 factory image for build `AP3A.240905.015.A2`.
     - Execute official `./flash-all.sh` script to restore stock Google firmware.
[Primary Source: Google Developers — Factory Images for Nexus and Pixel Devices, `https://developers.google.com/android/images`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

## 7. What Not To Do

7.1. **DO NOT relock the bootloader** with an unverified custom or baseline image. Relocking the bootloader while running an image signed with default test keys or unsigned images will cause Android Verified Boot (AVB) verification failure, locking the device into an unbootable state ("orange/red state brick").
[Primary Source: Google Android Source — Verified Boot — Locking and Unlocking, `https://source.android.com/docs/security/features/verifiedboot/boot-flow#locking-and-unlocking`, Access Date: 2025-05-16, Confidence: `VERIFIED`]

7.2. **DO NOT modify or disable Android Verified Boot flags** (e.g. `fastboot --disable-verity` or `--disable-verification`) unless explicitly required by a documented debugging step.
[Primary Source: DeeX Master Development Plan v1.0, Section 5.1, Access Date: 2025-05-16, Confidence: `VERIFIED`]

7.3. **DO NOT install Google Mobile Services (GMS)** or log into personal Google accounts on the hardware development device.
[Primary Source: DeeX Master Development Plan v1.0, Section 1.2 / 5.1, Access Date: 2025-05-16, Confidence: `VERIFIED`]

## 8. Relocking Policy

8.1. **Deferred to DeeX Boot Module**: Relocking the bootloader requires embedding a custom root AVB public key (`avb_custom_key`) into the Titan M2 hardware security element so that AVB validates the custom-signed images during early boot. Bootloader relocking is strictly **DEFERRED to the DeeX Boot module** (Chunk 6+).
[Primary Source: DeeX Master Development Plan v1.0, Section 5.2 / 16.3, Access Date: 2025-05-16, Confidence: `VERIFIED`]

8.2. **Stock Relock Procedure**: If the device must be relocked for stock testing, it MUST first be flashed back to official stock Google signed factory firmware (`https://developers.google.com/android/images`) before executing `fastboot flashing lock`.
[Primary Source: Google Developers — Factory Images for Nexus and Pixel Devices, `https://developers.google.com/android/images`, Access Date: 2025-05-16, Confidence: `VERIFIED`]
